# 경비업체 해지방어 Q&A 시스템

영업사원과 상담원이 고객 해지 요청 상황에서 즉시 활용할 수 있는 리텐션 가이드 웹앱입니다.

## 포함 콘텐츠

- 실제 현장용 해지방어 스크립트 20개
- 고객 유형별 심리 분석 및 대응 전략
- 해지 사유별 전략 카드
- 검색/카테고리/고객유형 필터
- 모바일, 태블릿, PC 반응형 UI

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## GitHub 배포 추천

1. GitHub 저장소 생성
2. 이 프로젝트 업로드
3. Vercel과 GitHub 저장소 연결
4. 자동 배포

## 데이터 수정 위치

- `data/scripts.ts`: 현장 스크립트 20개
- `data/customerTypes.ts`: 고객 유형별 전략
